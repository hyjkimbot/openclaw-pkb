The Method

The Zettelkasten

  • Atomic notes — one idea per note
  • Links over folders — connections, not categories
  • Write to think — noting is thinking
  • Emergence — ideas surface from the network

Store

CSV, not chat logs

# nutrition-log/2026-03.csv date,meal,intake,cal_lo,cal_hi,pro_lo,pro_hi,status 2026-03-17,Breakfast,omelette,420,420,32,32,confirmed 2026-03-17,Lunch,Asian Box chicken,680,750,42,48,confirmed
  • Token-efficient — 1 meal = 1 CSV row (~40 tokens). The agent reads an entire month in one pass.
  • Machine-readable — same file feeds Obsidian, pandas, matplotlib, dashboards. No parsing needed.
  • Durable originals — PDFs and lab reports stored in Google Drive, referenced by stable file ID. Text extraction happens once.

Generated from CSV with one script: plot_health_metrics.py
Calories & protein bands + mood, energy, sleep — all from the same logs.
